# ربات اشتراک‌گذاری فایل با لینک اختصاصی تلگرام (FileLink Bot)
### پیاده‌سازی رسمی و بومی Telegram Serverless Native

این مخزن شامل پیاده‌سازی حرفه‌ای، مقیاس‌پذیر و تست‌شده یک ربات اشتراک‌گذاری فایل در تلگرام با استفاده از زیرساخت بومی **Telegram Serverless** و پایگاه‌داده **SQLite** داخلی است.

## ۱. معرفی پروژه

**FileLink Bot** به کاربران امکان می‌دهد هر نوع فایلی (سند، تصویر، ویدئو، موزیک، پادکست، ویس یا انیمیشن) را در تلگرام ارسال کرده، برای آن کپشن و مدت اعتبار (انقضا) تعیین کنند و یک **لینک مستقیم اختصاصی تلگرامی** دریافت نمایند. هر فردی که این لینک را باز کند، فایل را بدون واسطه در گفتگوی خصوصی خود دریافت می‌نماید.

تمامی عملیات جابجایی فایل‌ها با استفاده از متد بومی `api.copyMessage` در ابر تلگرام انجام می‌شود و نیاز به هیچ‌گونه دانلود، آپلود یا مصرف پهنای باند دیتاسنتری روی سرورلس ندارد.

---

## ۲. ویژگی‌های کلیدی

- **Serverless Native خالص:** بدون نیاز به VPS، داکر، پروسه دائمی Node.js یا ردیس.
- **پشتیبانی از انواع فرمت‌های فایل:** Document, Photo, Video, Audio, Animation, Voice.
- **جریان منعطف تنظیم کپشن:** امکان نوشتن کپشن سفارشی تا ۱۰۲۴ کاراکتر یا انتخاب دکمه آماده «بدون کپشن».
- **مدیریت هوشمند انقضا:** تعیین مدت انقضا بین ۱ تا ۳۶۵۰ روز یا حالت دائمی (بدون انقضا) با پشتیبانی از ارقام فارسی و عربی.
- **انقضای تنبل (Lazy Expiration):** بررسی اعتبار در لحظه درخواست، بدون وابستگی به Cron یا دیمون‌های پس‌زمینه.
- **امنیت توکن‌ها:** تولید توکن‌های غیرقابل حدس با حداقل ۱۲۸ بیت انتروپی و کاراکترهای سازگار با دیپ‌لینک تلگرام.
- **مدیریت فایل‌ها توسط کاربر (`/myfiles`):** مشاهده لیست صفحه‌بندی‌شده، آمار دانلود و امکان فعال یا غیرفعال‌سازی فوری لینک‌ها.
- **شناسایی خودکار فایل‌های علمی و زیستی:** تشخیص هوشمند فایل‌های ماکرومولکولی پروتئین (`.pdb`, `.cif`)، توالی‌های ژنومی (`.fasta`)، مولکول‌های شیمیایی (`.sdf`) و شناسه‌های مقالات علمی (PubMed PMID).
- **تاب‌آوری و کنترل تکرار (Idempotency):** جلوگیری از پردازش رویدادهای تکراری و مدیریت کامل خطاهای Bot API تلگرام.

## ۴. پیش‌نیازها

- Node.js نسخه ۲۰ یا بالاتر (برای اجرای آزمون‌های محلی و CLI).
- یک حساب کاربری فعال تلگرام.
- دسترسی به CLI رسمی پلتفرم Telegram Serverless (`@tgcloud/cli`).

---

## ۵. ساخت ربات با BotFather

۱. در تلگرام به آیدی **@BotFather** پیام دهید.
۲. دستور `/newbot` را ارسال کنید.
۳. نام و نام کاربری (Username) دلخواه برای ربات خود تعیین کنید.
۴. توکن Bot API ارائه‌شده را در جایی امن ذخیره کنید (هرگز آن را داخل کد کامیت نکنید).

---

## ۶. فعال‌سازی Telegram Serverless

۱. در ربات @BotFather وارد منوی تنظیمات ربات خود شوید (`/mybots`).
۲. ربات موردنظر را انتخاب کرده و به بخش **Bot Settings** بروید.
۳. گزینه **Serverless** را انتخاب کرده و وضعیت آن را فعال (Enable) کنید.

---

## ۷. دریافت CLI Access Token

۱. پس از فعال‌سازی سرورلس در BotFather، دکمه یا دستور مربوط به دریافت **CLI Access Token** را بزنید.
۲. یک توکن متنی مجزا مخصوص CLI دریافت خواهید کرد. این توکن برای ورود به محیط کلاود تلگرام استفاده می‌شود.

---

## ۸. راه‌اندازی محیط محلی و تست

ابتدا تمام وابستگی‌های محیط توسعه را نصب کنید:

```bash
npm install
```

اجرای مجموعه کامل تست‌های تضمین کیفیت:

```bash
npm test
```

بررسی سلامت تایپ‌ها و عدم وجود خطای ساختاری:

```bash
npm run check
```

## ۹. ساخت کانال خصوصی آرشیو و ادمین کردن ربات

۱. یک **کانال خصوصی (Private Channel)** جدید در تلگرام ایجاد کنید (مثلاً با نام `FileLink Storage Archive`).
۲. ربات خود را به اعضای کانال اضافه کرده و آن را **ادمین (Administrator)** کنید.
۳. اطمینان حاصل نمایید که مجوز **ارسال پیام (Post Messages)** به ربات داده شده باشد.
۴. شناسه عددی کانال (یک عدد منفی نظیر `-1001234567890`) را به دست آورید (با فوروارد یک پیام از کانال به ربات‌های شناسه مانند @userinfobot یا @getmyid_bot).

---

## ۱۰. تنظیم شناسه کانال و مدیر ربات

با استفاده از دستورات CLI، تنظیمات اولیه را در جدول `app_settings` پایگاه‌داده دایر کنید:

```bash
# تنظیم شناسه کانال خصوصی آرشیو
npx tgcloud db query "INSERT INTO app_settings (key, value, updated_at) VALUES ('STORAGE_CHANNEL_ID', '-1001234567890', 1700000000) ON CONFLICT(key) DO UPDATE SET value=excluded.value;"

# تنظیم شناسه کاربری عددی ادمین اصلی
npx tgcloud db query "INSERT INTO app_settings (key, value, updated_at) VALUES ('OWNER_TELEGRAM_ID', '12345678', 1700000000) ON CONFLICT(key) DO UPDATE SET value=excluded.value;"

# تنظیم یوزرنیم ربات (بدون @)
npx tgcloud db query "INSERT INTO app_settings (key, value, updated_at) VALUES ('BOT_USERNAME', 'FileLinkBot', 1700000000) ON CONFLICT(key) DO UPDATE SET value=excluded.value;"
```

## ۱۱. استقرار (Deploy) و اجرای Migration

۱. ورود به اکانت سرورلس تلگرام:
   ```bash
   npx tgcloud login
   ```
۲. اعمال اسکیمای جداول پایگاه‌داده SQLite:
   ```bash
   npx tgcloud migrate
   ```
۳. مشاهده تفاوت‌های کد و انتشار پروژه:
   ```bash
   npx tgcloud push
   ```
۴. بررسی لاگ‌های زنده جهت اطمینان از عملکرد صحیح:
   ```bash
   npx tgcloud logs --follow
   ```

## ۱۲. دستورات ربات و راهنمای کاربری

- `/start`: خوشامدگویی، معرفی ربات و نمایش کیبورد عملیاتی.
- `/start f_TOKEN`: تحویل مستقیم فایل ثبت‌شده با توکن اختصاصی.
- `/myfiles`: مشاهده لیست فایل‌های فعال و غیرفعال کاربر به همراه لینک و تعداد دانلود.
- `/stats`: گزارش آمار فایل‌های ثبت‌شده و مجموع حجم آرشیو.
- `/cancel`: لغو نشست یا فرآیند آپلود فعال.
- `/help`: راهنمای جامع گام‌به‌گام کار با سیستم.
- `/privacy`: شرایط استفاده و حریم خصوصی فایل‌ها.

## ۱۳. مدیریت خطاها و تاب‌آوری

- **انتقال پایدار:** در صورتی که کپی کانال به دلیل تغییر دسترسی کانال با مشکل مواجه شود، لایه تحویل به صورت خودکار از مسیر ثانویه ارسال با `telegram_file_id` برای رساندن فایل به کاربر بهره می‌گیرد.
- **مدیریت خطای ۴۲۹ (Rate Limit):** سیستم با مانیتورینگ نرخ در لحظه، از قفل شدن اکانت ربات محافظت می‌کند.
- **جلوگیری از ثبت ناقص:** هیچ لینک دیپ‌لینکی فعال نخواهد شد مگر اینکه پیام منبع به طور کامل در کانال آرشیو ثبت و شناسه آن ذخیره شده باشد.

---

## ۱۴. ملاحظات امنیتی و حریم خصوصی

- **کنترل دسترسی:** کاربران تنها قادر به مشاهده و غیرفعال‌سازی فایل‌های ارسالی خود هستند.
- **عدم افشای سکرت‌ها:** توکن ربات، توکن CLI، شناسه کانال و استک تریس در پیام‌های خطا به کاربر فاش نمی‌شوند.
- **حفاظت در برابر حملات تزریق HTML:** تمامی رشته‌های ورودی کاربر (نام فایل و کپشن) پیش از نمایش در کلاینت تلگرام Escape می‌شوند.
- **جلوگیری از سوءاستفاده:** هر کاربر در هر لحظه تنها مجاز به داشتن یک نشست فعال آپلود است.

---

## ۱۵. محدودیت‌های شناخته‌شده و توسعه آینده

- تلگرام اجازه حذف پیام‌های قدیمی‌تر از ۴۸ ساعت در چت‌های خصوصی را نمی‌دهد؛ به همین دلیل، ابطال انقضا صرفاً لینک را غیرفعال کرده و فایل را از دسترسی دیگران خارج می‌سازد.
- بسته‌های چندتایی مدیا (Media Group) در این نسخه جهت جلوگیری از تفکیک ناخواسته فایل‌ها رد می‌شوند و در نسخه‌های آتی به صورت گروهی پشتیبانی خواهند شد.
