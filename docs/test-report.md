# گزارش جامع تست و تضمین کیفیت (Test Report)

این گزارش نتایج اجرای خودکار آزمون‌های واحد، یکپارچگی، همزمانی و اعتبارسنجی‌های امنیتی پروژه **FileLink Bot** را مستند می‌کند.

## ۱. خلاصه وضعیت تست‌ها

- **تعداد کل آزمون‌ها:** ۳۰ مورد
- **آزمون‌های موفق (Passed):** ۳۰ مورد (۱۰۰٪)
- **آزمون‌های ناموفق (Failed):** ۰ مورد
- **مدت زمان اجرا:** ۱.۲۳ ثانیه
- **ابزار اجرای آزمون:** Node.js Built-in Test Runner (`node --test`)
- **کیفیت کد (Lint & TypeScript):** کاملاً معتبر و بدون خطا

---

## ۲. تفکیک آزمون‌ها بر اساس سناریوها

### دسته ۱: فرآیند آپلود و رسانه‌ها (Upload & Media)
- [x] دریافت Document و استخراج نام، حجم و پسوند
- [x] دریافت Photo و انتخاب هوشمندانه بالاترین کیفیت
- [x] دریافت Video و استخراج ابعاد و طول مدت
- [x] دریافت Audio و استخراج نام خواننده و عنوان قطعه
- [x] دریافت Voice و طول مدت صدا
- [x] رد قاطعانه ارسال چندتایی و آلبوم‌ها (`media_group_id`)
- [x] رد استیکرها و پیام‌های ویدیویی دایره‌ای (`video_note`)
- [x] رد فایل‌های دارای محتوای حفاظت‌شده (`has_protected_content`)

### دسته ۲: فرآیند کپشن (Caption Flow)
- [x] دریافت کپشن سفارشی فارسی و متنی
- [x] رد کپشن‌های بالاتر از ۱۰۲۴ کاراکتر
- [x] عبور بدون کپشن با دکمه اختصاصی (`caption_skip`) و پاکسازی کپشن اصلی

### دسته ۳: کنترل انقضا و نرمال‌سازی ارقام (Expiration)
- [x] اعتبارسنجی اعداد صحیح بین ۱ تا ۳۶۵۰ روز
- [x] نرمال‌سازی ارقام فارسی (۰-۹) و عربی (٠-٩) به ارقام استاندارد
- [x] رد مقادیر نامعتبر (صفر، اعداد منفی، اعشاری، متنی و خارج از محدوده)
- [x] انقضای تنبل (Lazy Expiration) در لحظه درخواست دریافت دیپ‌لینک
- [x] پشتیبانی از حالت دائمی / بدون تاریخ انقضا (`null`)

### دسته ۴: ذخیره‌سازی و کانال خصوصی (Archive & Storage)
- [x] انتقال بدون دانلود فایل با `api.copyMessage` به کانال آرشیو
- [x] ثبت شناسه پیام آرشیوی و شناسه کانال
- [x] مدیریت خطاهای تلگرام (دسترسی ادمین، خطای ۴۲۹، حذف پیام منبع)
- [x] فعال‌نشدن لینک قبل از تأیید موفق آرشیو در کانال

### دسته ۵: تحویل فایل و دیپ‌لینک (Delivery & Deep Linking)
- [x] تولید توکن ۱۲۸ بیتی غیرقابل حدس با کاراکترهای مجاز دیپ‌لینک (کمتر از ۶۴ کاراکتر)
- [x] باز کردن لینک و تحویل فایل به پیوی کاربر گیرنده
- [x] جلوگیری از تحویل فایل‌های منقضی‌شده با پیام واضح فارسی
- [x] جلوگیری از تحویل فایل‌های غیرفعال‌شده توسط صاحب فایل
- [x] افزایش اتمیک شمارنده دانلود در دیتابیس
- [x] مسیر جایگزین تحویل بر اساس `file_id` در صورت بروز اشکال در کپی کانال

### دسته ۶: امنیت، همزمانی و محدودیت نرخ (Security & Concurrency)
- [x] تکرارناپذیری (Idempotency): نادیده گرفتن آپدیت‌های تکراری با کلید پیام
- [x] محدودیت نرخ مبتنی بر SQLite (بررسی پنجره زمانی بدون ردیس)
- [x] کنترل دسترسی: کاربران غیراز مالک نمی‌توانند فایل دیگران را تغییر وضعیت دهند.
- [x] جلوگیری از فعال‌سازی مجدد فایل‌هایی که زمان انقضای آن‌ها سپری شده است.
- [x] شناسایی و استخراج متادیتای ساختارهای علمی (PDB، FASTA، SDF، مقالات PubMed).
